# Backend structure

All code is under `src/main/java/com/mdevs/cinefy/`. Use LSP / `ls` for the files inside each package; this map only says what goes where.

| Package              | Contents                                                                                                                                                                                                                                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config/`            | `database/` (`CinefyTableNamingStrategy`), `general/` (`AppConfig` — mail, env, password encoder; `SecurityConfig` — CORS, filter chain, `CinefyAuthManagers` bean; `RedisConfig` — `RedisTemplate<String, Object>`)                                                                                                       |
| `controller/`        | One `@RestController` per area: halls, movies (TMDB), showtimes, booking, staff, client, client auth, management auth, payment gateways, statistics                                                                                                                                                                        |
| `filter/`            | `JwtAuthenticationFilter`, `CsrfValidationFilter` (see [security.md](security.md))                                                                                                                                                                                                                                         |
| `dto/`               | Request/response DTOs, one folder per domain (`auth`, `booking`, `client`, `email`, `hall`, `movie`, `payment`, `showtime`, `staff`, `statistics`). `RedirectionDTO` (`record RedirectionDTO(String url)`) sits at the top level because both the Paymob checkout redirect and the OAuth authorization-url response use it |
| `projection/`        | Spring Data query projections, one folder per domain                                                                                                                                                                                                                                                                       |
| `entity/`            | JPA entities; all domain enums live in `entity/enums/`, never beside their entity. Infrastructure enums live with their code: `ErrorCode` (`shared/exception/`), `AuthContext` and `TokenType` (`shared/security/`)                                                                                                        |
| `repository/`        | Spring Data repositories (extend `BaseRepository`, except `TmdbMovieRepository`)                                                                                                                                                                                                                                           |
| `service/`           | Business logic, one service per area plus cross-cutting ones (`CurrentUserService`, `JwtSessionService`, `OtpService`, `EmailService`, `InvalidJwtService`, `CacheService`)                                                                                                                                                |
| `job/`               | Scheduled jobs (see [jobs.md](jobs.md))                                                                                                                                                                                                                                                                                    |
| `aspect/`            | Request and transaction logging aspects (see [jobs.md](jobs.md#logging-aspects))                                                                                                                                                                                                                                           |
| `shared/annotation/` | `@PublicApi`                                                                                                                                                                                                                                                                                                               |
| `shared/exception/`  | `CinefyExceptionHandler`, `CinefyExceptionResponse`, `ErrorCode`, exception types under `types/`                                                                                                                                                                                                                           |
| `shared/oauth/`      | OAuth provider clients (see [auth.md](auth.md#oauth2-social-sign-in))                                                                                                                                                                                                                                                      |
| `shared/payment/`    | `PaymobClient` (see [payments.md](payments.md))                                                                                                                                                                                                                                                                            |
| `shared/security/`   | JWT, `AuthContext`, authorization manager, auth managers, cookie factory, CSRF matcher, `CredentialCipher`                                                                                                                                                                                                                 |
| `shared/validation/` | `ValidationPatterns` (shared regex constants for DTO `@Pattern`)                                                                                                                                                                                                                                                           |
| `shared/QrGenerator` | Ticket QR codes (ZXing)                                                                                                                                                                                                                                                                                                    |
| `utils/`             | `CookieUtil`, `ExceptionResponseMaker`, `LoggingUtil`                                                                                                                                                                                                                                                                      |

Email templates (Thymeleaf) are in `src/main/resources/templates/`: OTP verification and booking ticket. `EmailService` sends them `@Async`.
