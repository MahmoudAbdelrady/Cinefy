Connect your Paymob account

Two secret values let Cinefy talk to Paymob on your behalf.

These are sensitive credentials

Treat the API key like a password. Anyone who has it can charge your customers — never paste it into chat, email, or screenshots. Cinefy stores it encrypted and never shows it back to you in plain text.

A long string of about 250 characters. Paste the entire value as-is.

Where to find it

In your Paymob portal, open Developers → API Key. Click "Copy" next to the key. The portal also shows when it was last rotated.

A shorter string of about 32 hex characters. Used to verify that webhook callbacks are genuinely from Paymob.

Where to find it

Same area as the API key, under Developers → Webhooks. Look for "HMAC" — it's the hex string Paymob signs every callback with.
